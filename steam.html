THE COMPLETE LEARNING LOOP

Every ability needs five connected pieces

1

Check

Start near the child’s current level and look backward only when evidence points to a gap.

2

Understand

Manipulate a model and notice what changes and what stays the same.

3

Apply

Solve a changed problem independently without relying on the model.

4

Explain

Defend a method, compare strategies, or diagnose an error.

5

Fresh check

Return later with a new context before calling the ability stable.

  4. Allow drawing or spoken explanation so writing level is not mistaken for math level.

LEARNING EVIDENCE

A fast correct answer is one clue—not the finish line.

The system keeps four kinds of evidence separate and waits for a changed problem before calling learning stable.

01

Concept

Can the learner show what the relationship means with a model or diagram?

02

Procedure

Can the learner carry out the method accurately and efficiently?

03

Application

Can the learner choose and use the idea in a changed situation?

04

Explain & transfer

Can the learner justify, compare, correct, or generalize?
